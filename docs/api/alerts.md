# Alerts

> **Status: Experimental** — Alert events are generated by the monitoring system but advanced alert rules and notification routing are still being developed. The API surface may change in future releases.

Alert events generated by monitors when thresholds are exceeded.

## GET /alerts

List alert events across all monitors.

**Query parameters:**

| Param | Type | Default | Description |
|-------|------|---------|-------------|
| `page` | int | 1 | Page number |
| `limit` | int | 20 | Results per page (0–200) |
| `monitor_id` | uuid | — | Filter by monitor |
| `capability` | string | — | Filter by capability type |
| `severity` | string | — | Filter by severity level |
| `suppressed` | bool | — | Filter suppressed alerts |
| `acknowledged` | bool | — | Filter acknowledged alerts |

**Response:** `SuccessResponse[list[AlertEventResponse]]`


## GET /monitors/{monitor_id}/alerts

List alert events for a specific monitor. Same query parameters as above (except `monitor_id`).

---
